Bem-vindo(a)! Este repositório documenta minha jornada intensiva de 90 dias focada em Análise de Dados, cobrindo SQL, Excel e Power BI aplicados a negócios.

## 📚 O Caminho (Syllabus)

### ✅ Fase 1: SQL & Banco de Dados (30 Dias - Concluído)
*Foco em extração e manipulação de dados em bancos relacionais.*
- [x] Comandos Básicos (SELECT, FROM, WHERE) e Filtros Avançados
- [x] Agregações e Agrupamentos (GROUP BY, HAVING)
- [x] Joins e União de Tabelas (INNER, LEFT, RIGHT, UNION)
- [x] Window Functions e CTEs (Common Table Expressions)
- **Projeto Destaque:** Análise exploratória de dados de vendas.

### 🔄 Fase 2: Excel para Negócios (Dia 15 - Em Andamento)
*Foco em transformar planilhas em ferramentas de decisão.*
- [x] Lógica Booleana (E, OU, NÃO) e Condicionais (SE, SES)
- [x] Tratamento de Texto e Limpeza de Dados
- [x] **Engenharia de Busca:** PROCV (VLOOKUP), PROCH, SEERRO
- [ ] Tabelas Dinâmicas e Gráficos Avançados (Próximo)
- [ ] Dashboards Interativos (Próximo)

#### 📂 Destaque Recente:
> **[Sistema de Frente de Caixa (PROCV)](./EXCEL/Dia_15_Sistema_de_Busca_PROCV.xlsx)** > Automação de consulta de preços utilizando VLOOKUP e tratamento de erros para simular um sistema de vendas real.

### ⏳ Fase 3: Power BI & Visualização (Próxima Etapa)
*Foco em Storytelling e Inteligência de Negócios (BI).*
- Conexão e tratamento de dados (Power Query)
- Modelagem de Dados (Star Schema)
- Fórmulas DAX para Análise de Negócios
- Criação de Dashboards Interativos e Publicação
