# 🚀 90 Dias de Dados: De Iniciante a Analista Júnior

**Autora:** Jéssica Rocha  
**Objetivo:** Transição de carreira para Analista de Dados  
**Status Geral:** 🟡 Em andamento (Dia 61/90)  

Bem-vindo(a)! Este repositório documenta minha jornada intensiva de 90 dias focada em Análise de Dados, cobrindo SQL, Excel e Power BI aplicados a negócios.

---

## 📚 O Caminho (Syllabus)

### ✅ Fase 1: SQL & Banco de Dados (30 Dias - Concluído)
Foco em extração e manipulação de dados em bancos relacionais.
* Comandos Básicos (SELECT, FROM, WHERE) e Filtros Avançados
* Agregações e Agrupamentos (GROUP BY, HAVING)
* Joins e União de Tabelas (INNER, LEFT, RIGHT, UNION)
* Window Functions e CTEs (Common Table Expressions)
* **Projeto Destaque:** Análise exploratória de dados de vendas.

### ✅ Fase 2: Excel para Negócios (30 Dias - Concluído)
Foco em transformar planilhas em ferramentas de decisão.
* Lógica Booleana (E, OU, NÃO) e Condicionais (SE, SES)
* Tratamento de Texto e Limpeza de Dados
* Engenharia de Busca: PROCV (VLOOKUP), PROCH, SEERRO
* Tabelas Dinâmicas e Gráficos Avançados 
* Dashboards Interativos 
* **Destaque Recente:** Sistema de Frente de Caixa (PROCV) > Automação de consulta de preços utilizando VLOOKUP e tratamento de erros para simular um sistema de vendas real.

### 🔄 Fase 3: Power BI & Visualização (Dia 01 - Em Andamento)
Foco em Storytelling e Inteligência de Negócios (BI).
* **Dia 01:** Introdução teórica, interface e importação do primeiro dataset (Desempenho de Campanhas de Tráfego Pago).
* Conexão e tratamento de dados (Power Query)
* Modelagem de Dados (Star Schema)
* Fórmulas DAX para Análise de Negócios
* Criação de Dashboards Interativos e Publicação
